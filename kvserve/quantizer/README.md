# Quantizer

KV cache quantization module for hybrid precision compression in KVServe.

## Overview

The quantizer module implements hybrid precision quantization strategies for KV cache compression. It supports both **head-level** and **layer-level** splitting strategies to optimize memory usage while preserving model performance.

## Architecture

The quantization pipeline consists of three main components:

1. **Split Functions** (`split_func.py`): Split KV cache into low/high precision parts
   - `head_split` / `head_restore` / `head_reconstruct`: Head-level splitting
   - `layer_split` / `layer_restore` / `layer_reconstruct`: Layer-level splitting

2. **Quantization Functions** (`quantizer_func.py`): Core quantization operations
   - `quantize`: Min-max quantization with configurable axis strategies
   - `dequantize`: Restore original precision from quantized data

3. **KVServe Quantizer** (`kvserve_quantizer.py`): Main quantizer implementation
   - Implements `Quantizer` interface from `kvserve.manager.components`
   - Coordinates splitting and quantization operations
   - Manages quantization metadata for dequantization

## Usage

### Basic Usage with Compression Manager

```python
import torch
from kvserve.manager import CompressionManager, CompressionConfig
from kvserve.quantizer import KVServeQuantizer

# Generate random tensor for shape [k/v, num_blocks, block_size, num_heads, head_size]
kv_cache = torch.randn(2, 128, 32, 8, 128, dtype=torch.bfloat16, device="cuda")

# Configure compression with quantizer
config = CompressionConfig(
    enabled=True,
    pipeline=["quantizer"],
    quantizer_config={
        "model_name": "Llama-3.1-8B-Instruct",
        "hybrid_ratio": 0.3,
        "high_key_max_value": 16,
        "high_value_max_value": 16,
        "low_key_max_value": 12,
        "low_value_max_value": 12,
        "axis_key": "channel",
        "axis_value": "token",
        "split_type": "head",
    },
    min_compress_size=1024,
)

# Create compression manager
manager = CompressionManager(
    config=config,
    quantizer=KVServeQuantizer,
)

# Compress KV cache
compressed = manager.compress(
    layer_id=0,
    kv_data=kv_cache,  # [2, num_blocks, block_size, num_heads, head_size]
    request_id="req_001",
    metadata={"block_indices": [0, 1, 2]},
)

# Decompress KV cache
decompressed = manager.decompress(
    layer_id=0,
    compressed_data=compressed,
)

# Calculate cosine similarity between original and decompressed KV cache
cosine_similarity = torch.nn.functional.cosine_similarity(kv_cache.flatten(), decompressed.flatten(), dim=0)
print(f"Cosine similarity: {cosine_similarity.item()}")
```

## Configuration Parameters

### KVServeQuantizer Parameters

- `model_name` (str, default: `"Llama-3.1-8B-Instruct"`): Model name for loading head scores from CSV file. The quantizer looks for `<model_name>_scores.csv` file generated by DuoConfig module.

- `hybrid_ratio` (float, default: `0.3`): Ratio of heads/layers to use low precision. 

- `high_key_max_value` (int, default: `16`): Maximum quantization value for high precision keys. Higher values preserve more precision.

- `high_value_max_value` (int, default: `16`): Maximum quantization value for high precision values.

- `low_key_max_value` (int, default: `12`): Maximum quantization value for low precision keys. Lower values save more memory.

- `low_value_max_value` (int, default: `12`): Maximum quantization value for low precision values.

- `axis_key` (str, default: `"channel"`): Quantization axis strategy for keys:
  - `"channel"`: Compute min/max along dimensions [0, 1] (block and block_size)
  - `"token"`: Compute min/max along dimensions [2, 3] (head and head_size)
  - `"tensor"`: Compute min/max across all dimensions

- `axis_value` (str, default: `"token"`): Quantization axis strategy for values (same options as `axis_key`).

- `split_type` (str, default: `"head"`): Split strategy:
  - `"head"`: Split attention heads within each layer based on head scores
  - `"layer"`: Split entire layers (currently selects last 33% layers as low precision)

## Quantization Process

### Compression Pipeline

1. **Split**: Split KV cache into low and high precision parts
   - Head-level: Split heads based on DuoAttention scores
   - Layer-level: Split layers based on layer scores mask

2. **Quantize**: Apply min-max quantization to each part
   - High precision parts: Use `high_key_max_value` / `high_value_max_value`
   - Low precision parts: Use `low_key_max_value` / `low_value_max_value`
   - Store quantization metadata (min_val, scale, dtype)

3. **Concatenate**: Concatenate quantized parts back together

### Decompression Pipeline

1. **Restore**: Split concatenated tensor back into low/high precision parts

2. **Dequantize**: Restore original precision using stored metadata
   - Formula: `Real = Quantized * Scale + Min_Value`

3. **Reconstruct**: Recombine parts back to original shape and order

## Components

### Split Functions

- **`head_split(layer_id, tensor, head_scores)`**: Split tensor into low/high precision heads based on head scores mask
- **`head_restore(layer_id, tensor, head_scores)`**: Restore concatenated tensor back into separate low/high precision heads
- **`head_reconstruct(layer_id, low_tensor, high_tensor, head_scores)`**: Reconstruct original tensor with heads in original order
- **`layer_split(layer_id, tensor, layer_scores)`**: Split tensor based on layer scores (entire layer or empty)
- **`layer_restore(layer_id, tensor, layer_scores)`**: Restore tensor based on layer scores
- **`layer_reconstruct(layer_id, low_tensor, high_tensor, layer_scores)`**: Reconstruct tensor from low/high precision parts

### Quantization Functions

- **`quantize(max_value, tensor, axis)`**: Quantize tensor using min-max quantization
  - Maps values from [min, max] to [0, max_value]
  - Returns quantized tensor (uint8) and metadata
- **`dequantize(quantized_tensor, metadata)`**: Restore original precision
  - Uses stored min_val and scale from quantization metadata

## Dependencies

The quantizer module requires:
- Head scores CSV files generated by `kvserve.config.duo_config` module
- See [DuoConfig README](../config/duo_config/README.md) for generating head scores
